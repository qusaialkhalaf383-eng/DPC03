12. Limitations

  • All data is synthetic. Class relationships (including the near-deterministic ones flagged for Reverse_Engineer and OEM_Purchase) reflect the synthetic generator's logic, not verified real-world engineering judgment.
  • Hyperparameter tuning ran on a single-CPU-core sandbox with a reduced trial budget (10 trials/model instead of 30+) — worth widening on production hardware before treating current hyperparameters as final.
  • Calibration was fit on half of a 450-row validation set (~225 rows) — thin for lower-prevalence targets.
  • The generalization challenge covers one held-out sector; it demonstrates the model isn't overfitting to sector-specific noise, but cannot substitute for validation against independently-collected real engineering decisions.
  • The lifecycle cost optimizer uses illustrative, documented assumptions (see src/optimizer.py), not a calibrated finance model.
  • Out-of-distribution detection (Isolation Forest on numeric features) is a first pass, not a full categorical-aware novelty model.
